# FantAbba Final

Final architecture: one entrypoint, one auction engine, real 8x500 references when present, explicit estimates otherwise, live bid decision, constrained 3/8/8/6 roster builder, complete searchable player database, and simulation.

The product is designed around dynamic auction values: values must update as money is spent, roster needs change, and positional scarcity changes. The builder must never sacrifice legality for raw player score.
